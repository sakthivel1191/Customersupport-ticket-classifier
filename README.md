Customer Support Ticket Classifier
Customer Support Ticket Classifier using TF-IDF, Logistic Regression, DistilBERT, and FastAPI to predict ticket categories and priorities.

Technologies Used
Python
TF-IDF
Logistic Regression
DistilBERT
FastAPI

Project Overview
This project uses Natural Language Processing (NLP) and machine learning to classify customer support tickets into relevant categories and predict their priorities.
